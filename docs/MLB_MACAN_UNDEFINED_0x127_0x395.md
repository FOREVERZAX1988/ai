# Macan 未定义信号 0x127 / 0x395 —— 收尾结论（2026-09-09 步骤B）

> 用户问题：这两个 DBC 未收录信号是不是距离？若不是，是什么物理量？能不能拿来起点作用？

## 实测（probe_0x127_0x395 / probe_0x127c，0004 seg20 + 00049 seg12）

### 0x127 (295, bus2=src2 与 src128/转发, 20Hz, DLC8) —— 近恒定状态/环境字
```
原始帧(典型): 00 10 45 3c 78 ee 00 00
b0: 恒定 0                    b3: 恒定 0x3c=60
b1: 0/16/240 (0/1% 变化)      b4: 恒定 0x78=120
b2: 65~77 (0x41~0x4d, 0/1%)  b5: 恒定 0xee=238
                              b6,b7: 恒定 0
```
- 全部字节近乎恒定（change% ≈ 0~1%），无与目标距离/速度一致的大跳变。
- 结论：**不是距离/速度物理量**，是车辆/环境状态或配置字（类似“雷达环境标记”），
  唯一活用是作为 ~20Hz 恒定状态位（区分 ACC 状态档），对纵向无增益。

### 0x395 (917, bus2/src2 与 src128, 10Hz, DLC8) —— 状态/诊断帧（带计数+漂移量）
```
原始帧(典型): 10 [cnt 0-15] 12/22 00 [b4 70~83] [b5 96~115] [b6 66~101] 1c
b1: 4bit counter 0→15 循环（100% 变化，delta=1 rollover）
b2: 0x12/0x22 = 状态档（18/34）
b4: 70~83 (6% 变)  b5: 96~115 (30% 变)  b6: 66~101 (38% 变)  b7: 0x1c/0x5c
相关（对 lead dRel / vEgo）：
  b5: corr(lead)=-0.07  corr(vEgo)=+0.29
  b6: corr(lead)=-0.02  corr(vEgo)=-0.20
```
- b1 是稳定 4bit 时基计数；b2 是 ACC/速度状态档；b4/b5/b6 虽有变动但
  与真实目标距离、vEgo 相关性极弱（|corr|<0.3），不具备距离/速度物理量特征。
- 结论：**0x395 是雷达/ACC 状态诊断帧**（与前 0909 扫描“雷达状态报文”一致），
  不是目标测距测速信号。

## 能不能起点作用？
- **不能**用于距离/速度增强：两者都不携带目标 d/v 物理量。
- 唯一可复用：0x395 的 4bit 计数 b1 提供稳定时间基（10Hz），b2 提供 ACC 状态档
  —— 若做状态同步/时序对齐（类似 verz 桥接）可作辅助参考，属于低成本兜底，非核心。
- 0x127 全近恒定，无实用价值。
