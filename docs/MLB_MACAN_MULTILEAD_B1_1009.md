# Macan 多目标排查：视觉 lead0 偏差大时，lead1/lead2 是否更贴近 B1 雷达 (2026-09-10 会话末)

> 前置：B1 单表 t=0.008969·idx+0.332 已在 A2/A3/CC 三处同源落地（radard.py / opendbc radar_interface.py / carcontroller.py）。
> 用户新思路：当视觉 lead0 与雷达距离偏差较大时，疑似锁定的目标不同（旁车道有车）——应检查视觉 lead1/lead2
> 是否与雷达更一致（视觉读到的是多目标 lead one/two/three）。
> 工具：`ai/tools/scan_multilead_radar_b1_0910.py`（已提交 5374923，ai 子模块 + 主仓 bump）。

## 口径（本轮关键修正）
- 视觉 lead x[0] 取 modelV2.leadsV3[i].x[0]（三目标并存）。
- 雷达距离 B1：d_rad = (0.008969·idx + 0.332)·max(v_wheel,5)。
- **信号总线**：idx(ACC_02) 取 **bus2(src==2)**（原厂，op 无法篡改）；**轮速(0x103/259)取 bus0(src 0/1)**；
  ACC_04 前车速度 bus2。⚠️ 轮速不在 bus2，早前 src==2 全门控把轮速全滤掉 → 归零，已修正。

## 结果（0071/0072 新分支 + 0004 旧分支采样，N=579 有效 lead 帧）
- lead0 有效 579 / lead1 有效 579 → **视觉三目标几乎总是并存**（lead2 也 100% 存在）。
- rel>0.15（视觉 lead0 vs B1 雷达偏差超 15%）帧共 104 帧：
  - lead0 med|Δ| = 7.1m（radar≈27m、lead0≈35m）
  - **lead1 med|Δ| = 7.1m、lead2 = 7.2m —— 与 lead0 几乎相同**
  - **[lead1 比 lead0 更贴近雷达 (>0.5m)] 占比仅 1.0%**

## 结论
1. **视觉三目标（lead0/1/2）距离彼此高度一致**，在 lead0 与雷达偏差大的帧上，lead1/lead2 并不会显著更贴近雷达。
   → 偏差**不是「视觉锁定旁车道不同目标」造成的**；三目标同时指向同一尺度，与雷达的差是**系统性尺度差**，
   不是目标误配。
2. 这佐证了前几轮结论：视觉（三目标同尺度）与 B1 雷达的残余差（NEW 分支 ~+2.8~/，OLD ~−0.9m）来自**两传感器
   固有尺度差异**（视觉偏近/雷达偏远或反之），而非目标选择问题。A2 融合用「rel=|d_vis−d_stock|/d_stock 判据」
   已能守住——B1 下替换率低（池化 5.9~9.7%），多数帧走 70/30 平滑混合。
3. 建议路测重点：若想进一步减小视觉/雷达差，方向是**尺度平移/缩放的微调**（单系数），而非多目标切换机制。
