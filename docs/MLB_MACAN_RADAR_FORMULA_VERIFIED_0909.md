# Macan 雷达距离公式 —— 重新验算最终结论 (2026-09-09)

> 用户授权全部工具 + 要求重新验算雷达距离推算公式。本轮独立复核上一会话两条矛盾结论，给出唯一正确公式。

## ✅ 唯一正确公式（已独立确认）
```
d_rel = t(ACC_Abstandsindex) · v_ego          [m]
```
- `t(idx)` 加速度公式（REFIT_0909 已给、本轮以真实雷达轨道复核 +0.5%）：
  ```
  t = 0.008718 · idx + 1.0178      [s]   （适用 idx≈100~560，误差≈0.5~2%）
  ```
- `v_ego`：ESP_03 四轮轮速 `ESP_*_Radgeschw`(16/28/40/52|12 @0.1km/h) 均值 ÷3.6 → m/s
- `idx = ACC_02.ACC_Abstandsindex`(24|10)；`v_lead = ACC_04.ACC_Geschw_Zielfahrzeug`(40|10 ×0.32 **km/h**)÷3.6
- `v_rel = v_lead − v_ego`

## 一、三个关键结论（本轮独立数据支撑）
1. **0004 确有高速跟车段（用户一直正确，早前扫描错误）**
   ESP 轮速全量扫 0004 全 59 段：seg19~27 达 60~95km/h（seg20 峰值 95.1、seg21 89.6、22 86.2、23 81.7…），
   錄覆盖用户所说 ~1140~1620s 高速窗。早前"全段≤24~26km/h"的结论是扫描脚本 glob/解析错误所致。

2. **旧查表时距表系统性低估 ~17%（绝对尺度，真实雷达轨道验证）**
   seg21 有真实雷达轨道注入（radar=True, 52 帧），以其 dRel 为真值：
   - 旧表 `interp(idx)→t→d=t·v`：**表/雷达 = 0.823，误差 −17.5%**（低估）
   - 新线性 `t=0.008718·idx+1.0178`：**表/雷达 = 1.005，误差 +0.5%**（准确）
   → 坏的只是旧表 t 值偏低 ~17%，公式形态 `d=t·v` 没错。

3. **公式形态验证（运动学一致性，独立于雷达）**
   连续高速跟车块 1s/0.5s 滑窗，表预测 Δd 对实测 ∫vrel·dt 回归：
   中段 idx200-400：**slope≈1.02, bias≈−0.2m**（表与真实运动学闭合）。
   低idx(0-100)与高idx(400+)样本少、量化分辨率不足，slope 偏低(0.58/0.76)——是样本问题非公式系统错误。

## 二、为何"纯数据 lstsq 从零拟合"不稳（排除法）
fit_abstands_canonly v1/v2/v3 在稳态跟车(vrel≈0)有**规范/可辨识性问题**：
每块初始距离 d0 吸收绝对尺度 → t(idx) 自由度架空 → 拟合出 t≈16~25s 非物理值。
⇒ 正确路径不是"从零拟合 t"，而是**在真实/运动学锚点上校准**：
  - 绝对尺度 → 用真实雷达轨道 dRel（seg21 之类 radar=True 帧）
  - 相对尺度 → 用 ∫vrel 运动学闭合

## 三、明确废弃的旧结论
- ~~http／"0004 全 59 段低速，方案A不可行"~~ → 错（轮速证伪）
- ~~距离模型 d=g(idx)（不乘 vEgo，CALIB_FIXED_0909）~~ → 证伪：
  用 14164 高速帧，时距模型 `d=t·v` 中段闭合 slope≈1；而距离模型残差·v 相关性更高(中段 +0.53 vs +0.34)，
  且 seg21 真实雷达轨距随 vEgo 显著变化（71→83m，vEgo 80→77），证明 idx 表达的**是时距/距离随速变化**，非纯距离。
  结论：**时距模型 `d=t(idx)·v` 正确**。
