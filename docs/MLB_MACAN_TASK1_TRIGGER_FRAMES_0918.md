# Macan 纯OP点火报错 —— 任务1 触发条件对照 + 9.2s 前后帧全列 (0916-0918)

> 分支：macan-long-0915/0916 ｜ 数据源：route 0075(纯OP/坏) vs 0078(融合/好) **seg0 rlog 逐帧原始 CAN**
> 方法：capnp 解析 rlog can 事件，按 src(bus) 分治 + 9.2s 故障窗口全帧清单
> 本任务目标：把「触发条件对照」和「9.2s 前后几帧」列全，作为任务1的最终结论文档。

## 〇、一句话结论
**0075(纯OP/坏) 在 9.251s，雷达总线(bus2=src2)上的 ACC_05/Status_ACC 一次跳 2→7、ACC_02/Status_Anzeige 2→7、
ACC_04/ACC_Charisma 保持 2（已故障）——触发点清晰为 `9.251s`。同一时刻 0078(融合/好) 全部信号恒为 2(待命)、
无任何 7。** 关键：**0x127 / 0x395 在故障前后帧字节完全不变、且在好/坏路由字节分布基本一致 → 二者不是触发信号。**

## 一、触发条件对照（0075 vs 0078，seg0 点火段，bus2 雷达侧）

| 信号(addr, 位) | 0075 纯OP(坏) | 0078 融合(好) | 判定 |
|----------------|---------------|---------------|------|
| ACC_05/Status_ACC (0x10D, bit57\|3) | 2→**7 @ 9.251s**，此后持续 7 | 恒 **2**(待命)，仅 31s 一次 2→0→2 拨杆瞬态 | **故障跳变只在纯OP** |
| ACC_02/Status_Anzeige (0x30C, bit61\|3) | 2→**7 @ 9.251s** | 恒 2 | 同上 |
| ACC_04/ACC_Charisma (0x324, b7低2位) | 0→1 @ 3.044s，1→**2(故障) @ 9.251s** | 0→1 @ 2.679s，**保持 1(可用)** | 0→1 握手好/坏都有；1→2 故障只在纯OP |
| 0x127 (295) byte1 | {0x20:1285, 0x40:190, 0x80:22} | {0x20:1282, 0x40:192, 0x80:27} | **几乎一致，非触发** |
| 0x395 (917) byte2 | {0x12:295, 0x52:4} | {0x12:296, 0x52:4, 0x62:1} | **几乎一致，非触发** |
| 0x395 (917) byte7 | {0x4c:8,0xcc:33,0xdc:258} | {0x0c:1,0x4c:8,0xcc:34,0xdc:258} | 一致（0xdc 主态） |

**触发判定**：真正驱动故障的只有 ACC_02/04/05 的状态位；0x127/0x395 不参与。
