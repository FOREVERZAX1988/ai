## 结论
**距离推算公式（已验证，纯 CAN）**：
```
d_rel = t(ACC_Abstandsindex) × v_ego        [m]
其中 t(idx) 是时距表（_macan_abstands_t），v_ego 用 ESP 四轮轮速 ESP_*_Radgeschw 解出。
```

## 二、重新验算结果（纯 CAN 运动学，窗口积分一致性）
方法：在连续跟车块内取 1s/0.5s 滑窗，比较
  `表预测距离变化 Δd = t(idx2)·v2 − t(idx1)·v1`
  `实测相对位移   Δs = ∫(v_lead − v_ego)dt`

**整体回归（N=37091 窗）**：`Δd_pred = 0.946·Δs − 0.48 [m]`，残差 RMSE=3.71m（Δs∈[−7.4,10.9]）

按 idx 带：
| idx 带 | n | slope(≈1好) | bias(m) |
|--------|-----|------|------|
| 0–100 | 1159 | 0.575 | −0.38 |
| 100–200 | 8321 | 1.069 | −1.20 |
| **200–300** | **14725** | **1.018** | **−0.21** |
| 300–400 | 11051 | 0.978 | −0.54 |
| 400–500 | 1083 | 0.761 | +0.59 |

**解读**：
- **中段 idx 200–400（高速常用带）表几乎完美**：slope≈1.02、bias≈−0.2m —— 距离公式 `d=t·v` 在该带是物理准确的。
- 低 idx（0–100，近距离 t≈0.8–1.0s）与高 idx（400+，超远距离）样本少、slope 偏低（0.58/0.76）——**属于实测样本与量化分辨率不足，非公式系统错误**；且低idx带 t 接近常数0.8s，vrel 可测范围很小，回归被噪声主导。

## 三、直接物理公式示例（供直接用）
用当前时距表（_macan_abstands_t，idx 节点 _macan_abstands_idx，27..1021）：
```
t = interp(ACC_Abstandsindex, _macan_abstands_idx, _macan_abstands_t)   # s
d_rel = t × v_ego_mps                                             # m
v_lead_mps = ACC_Geschw_Zielfahrzeug_kmh / 3.6
v_rel = v_lead − v_ego                                            # m/s
```

## 四、为何之前"方案A纯lstsq拟合"不稳
- 纯数据 lstsq（fit_abstands_canonly_v1/v2/v3）在**稳态跟车（vrel≈0）**时存在**规范/可辨识性问题**：
  每块的初始距离 d0 会吸收绝对值尺度，t(idx) 自由度被架空 → 拟合出 t≈16–25s 的非物理值。
- 正确做法不是"从零拟合 t"，而是**验算/校准现有表**：用运动学一致性确认 t 表与公式 d=t·v 无系统偏差（本次已做到）。

## 五、落地建议
1. 保持现表 `d=t(idx)·v_ego`（中段已验证准确），无需重拟合。
2. 若需提升低idx/高idx带的精度，需补拍**近距离慢速**与**超远距离**的跟随样本（非高速样本）。
3. 代码位置：opendbc_repo/opendbc/car/volkswagen/radar_interface.py `_update_macan`（t 插值 + d_rel = t·v_ego）。
